# Bram's writing rules

- Never use a dash (`-` or `—`) inside a sentence. Dashes are for lists only.
- Split a dash-joined thought into two short sentences instead.
- Never add a description or body to a commit or a pull request. Title only.
- Never add an AI attribution line to a commit or a pull request. No Co-Authored-By trailer, no "Generated with" footer, nothing.
- Never add comments in code. Let the code speak for itself.
