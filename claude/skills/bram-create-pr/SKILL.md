## Pull request conventions

- Title: short (under ~70 chars), plain, no conventional-commit prefix.
- Body: a `## Summary` (1-3 bullets) and a `## Test plan` (checklist of what was/should be verified) — nothing else unless asked.
- Confirm before pushing or opening the PR, unless already told to proceed autonomously.

Repo-level convention wins: if the repo has its own PR template or `CONTRIBUTING` guide, follow that instead.
