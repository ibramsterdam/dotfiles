## Documentation style

- Write in English at a B1 level: short, simple sentences.
- Prefer unordered lists over long paragraphs.
- Keep it plain. Avoid jargon unless necessary, and skip filler.

Repo-level convention wins: if the repo already has its own docs style guide, follow that instead.
